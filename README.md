# CodeAlpha FAQ Chatbot

## Overview
This project is a simple AI-powered FAQ Chatbot built using Python and Streamlit. It uses Natural Language Processing (NLP) with TF-IDF Vectorization and Cosine Similarity to find the most relevant answer from a list of frequently asked questions.

## Features
- Interactive chatbot interface
- FAQ dataset stored in CSV
- TF-IDF vectorization
- Cosine similarity matching
- Handles unknown questions gracefully

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn

## Project Files
- app.py
- faq.csv
- requirements.txt

## How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
